# Sistema de Cadastro
- Sistema simples de cadastro e login feito para praticar java, sqlite, e segurança de senhas
- O sistema contem:
  - Cadastro de usuários
  - Login com verificação de senha (hash BCrypt)
  - Persistência de dados em banco SQLite
## Tecnologias ultilizadas
- Java
- SQLite
- JDBC
- BCrypt (jBCrypt) para hash de senhas
- Maven para gerenciamento de dependência
